# Java Exercícios ☕

Repositório criado para acompanhar e documentar minha evolução na trilha de aprendizado em Java Backend. 

Estou estudando diariamente para construir uma base sólida na tecnologia, focando em boas práticas de mercado, com o objetivo de conquistar minha primeira oportunidade de **Estágio em Desenvolvimento Java**.

## 🚀 O que estou estudando e praticando:
*   **Lógica de Programação:** Variáveis, operadores, estruturas condicionais e estruturas de repetição (`for`, `while`, `do-while`, `switch-case`).
*   **Manipulação de Dados:** Arrays (vetores) e Strings.
*   **Coleções Dinâmicas:** `ArrayList` e manipulação de listas.
*   **Orientação a Objetos (OOP):** Classes, atributos, métodos, construtores, sobrecarga e encapsulamento (`private`, Getters e Setters).
*   **Versionamento:** Controle de versão e organização de repositórios com Git e GitHub.

## 📂 Organização do Repositório
Para manter o portfólio limpo e profissional, cada pasta corresponde a um assunto específico da trilha de estudos, contendo os exercícios práticos aplicados a cenários do mundo real.

*Este repositório é atualizado constantemente conforme avanço no roadmap de Java Backend.*
